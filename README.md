# Billions Fan Website

A fan-made website dedicated to the Billions TV Series. It includes character profiles, animations, and a gallery with a modern design inspired by Apple-style interfaces.

Live Website:
https://fareedumar20-prog.github.io/Billions-fan-website/

---

## Features

Character Profiles

* Real Name
* Character Name
* Net Worth
* Images

Gallery

* Smooth scroll animations
* Staggered image reveal
* Hover zoom effects
* Image preview

User Interface

* Dark theme
* Glass-style navigation bar
* Responsive design
